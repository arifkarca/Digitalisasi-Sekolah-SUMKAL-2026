# Portal Monitoring Digitalisasi Pembelajaran 2026 (SUMKAL - Vokasi & Terpadu)

Satu pintu dashboard GitHub Pages dengan halaman login password di muka, yang memuat switcher untuk berpindah langsung antara tampilan **Sekolah Vokasi** dan **Sekolah Terpadu** dari masing-masing Google Sheets (`SUMKAL`).

## Cara Konfigurasi (`app.js`)
1. Ubah `PASSWORD: 'PLNODS2026'` dengan kata sandi pilihan Anda.
2. Isi `VOKASI.spreadsheetId` dengan ID Google Sheets Sekolah Vokasi Anda.
3. Isi `TERPADU.spreadsheetId` dengan ID Google Sheets Sekolah Terpadu Anda.
